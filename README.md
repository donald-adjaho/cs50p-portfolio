# CS50P - Introduction to Programming with Python

This repository contains my complete portfolio of solutions and projects completed for **CS50P**, Harvard University's Introduction to Programming with Python course.

## 📌 Note to Recruiters
**Timeline of Work:** 
These exercises were originally completed, tested, and submitted between **[Start Month, Year]** and **[End Month, Year]** via the official CS50 `me50` submission system. 
This repository is a consolidated archive of my work, extracted into a clean folder structure for portfolio presentation purposes. The code reflects the skills I acquired during that period.

## 🧠 Skills & Concepts Mastered
Through these problem sets, I developed a strong foundation in Python and software development best practices, including:

*   **Core Python:** Variables, Functions, Conditionals, Loops, and Data Structures (Lists, Dicts, Sets, Tuples).
*   **Error Handling:** Exception handling (`try/except`) and input validation.
*   **File I/O:** Reading and writing CSV files, processing images, and handling text files.
*   **Libraries:** Utilizing standard libraries (`random`, `sys`, `csv`, `re`) and third-party packages (`requests`, `Pillow`, `pytest`, `cowsay`).
*   **Regular Expressions (Regex):** Pattern matching, validation, and data extraction.
*   **Object-Oriented Programming (OOP):** Creating classes, methods, properties, and inheritance.
*   **Testing:** Writing and running Unit Tests using `pytest`.

## 📂 Repository Structure & Problem Sets
The repository is organized into directories, grouped by the core concepts they address. 

### 🔹 Functions & Variables
*   `einstein/` - Mass-energy equivalence calculation.
*   `faces/` - String replacement and emoji conversion.
*   `indoor/` - User input handling and string manipulation.
*   `playback/` - String manipulation (slowing down speech).
*   `tip/` - Basic mathematical calculations.

### 🔹 Conditionals & Logic
*   `bank/` - Validating user input with conditional statements.
*   `deep/` - Answering questions based on string matching.
*   `extensions/` - File extension identification.
*   `interpreter/` - Parsing math expressions from user input.
*   `meal/` - Time-based conditional logic.

### 🔹 Loops & Iterations
*   `camel/` - String formatting (converting camelCase to snake_case).
*   `coke/` - Simulating a vending machine using while loops.
*   `plates/` - Validating license plate formats.
*   `taqueria/` - Menu ordering system using dictionaries.
*   `twttr/` - Text processing (vowel removal).

### 🔹 Exceptions & Error Handling
*   `fuel/` - Fraction conversion and handling `ValueError`/`ZeroDivisionError`.
*   `grocery/` - Building a shopping list with dictionary counting.
*   `outdated/` - Date validation and formatting.

### 🔹 Libraries & APIs
*   `adieu/` - Saying goodbye in multiple languages.
*   `bitcoin/` - Fetching real-time cryptocurrency prices via APIs.
*   `emojize/` - Using the `emoji` library.
*   `figlet/` - Using the `pyfiglet` library for ASCII art.
*   `game/` - Guessing game using the `random` module.
*   `professor/` - Math quiz using `random`.
*   `response/` - Validating email formats.
*   `shirtificate/` - Generating PDFs using the `fpdf2` library.

### 🔹 File I/O & Data Processing
*   `lines/` - Counting lines of code in a file.
*   `pizza/` - CSV file parsing and tabulation.
*   `scourgify/` - Reading and writing CSV files.
*   `shirt/` - Image processing using the `Pillow` library.

### 🔹 Regular Expressions (Regex)
*   `numb3rs/` - Validating IP addresses.
*   `um/` - Removing filler words from speech.
*   `watch/` - Extracting YouTube video IDs from URLs.
*   `working/` - Parsing time ranges.

### 🔹 Object-Oriented Programming (OOP)
*   `jar/` - Creating a cookie jar class with properties and methods.
*   `seasons/` - Calculating the current season based on the date.

### 🔹 Unit Testing (`pytest`)
*   *(Note: The `bank`, `fuel`, `plates`, and `twttr` folders also contain unit tests written to validate the logic of the exercises).*

## 🚀 How to Run
Most of these scripts are standalone Python files. To run any of the exercises, ensure you have Python installed, navigate to the specific folder, and run:
```bash
python filename.py
```
